## Présentation

| | |
| --- | --- |
| Type | Trancheur (génère le G-code à partir des modèles 3D) |
| Licence | Open source (AGPL-3.0) |
| Origine | Dérivé de Bambu Studio, inspiré de PrusaSlicer, Cura et SuperSlicer |
| Imprimantes | Bambu Lab, Prusa, Creality, Voron et bien d'autres |
| Systèmes | Windows, macOS, Linux |
| Site | [orcaslicer.com](https://www.orcaslicer.com) · [code source](https://github.com/SoftFever/OrcaSlicer) |

## Points forts

- Outils de calibration intégrés : tour de température, débit, etc.
- Contrôle fin des parois et de la position de la couture.
- Envoi direct aux imprimantes en réseau (Klipper, PrusaLink, OctoPrint).
- Un seul logiciel pour plusieurs marques d'imprimantes, par exemple l'[A1 mini]({{ '/docs/materiel/bambu-lab-a1-mini/' | relative_url }}) et l'[Ender 3 V2]({{ '/docs/materiel/creality-ender-3-v2/' | relative_url }}).

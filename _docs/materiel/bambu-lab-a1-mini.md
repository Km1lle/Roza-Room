## Caractéristiques

Source : [fiche technique officielle Bambu Lab](https://store.bblcdn.com/6cddc28fcb5a4a34975cfc7a23c83491.pdf).

| Caractéristique | Valeur |
| --- | --- |
| Volume d'impression | 180 × 180 × 180 mm |
| Buse fournie | 0,4 mm, acier inoxydable (0,2 / 0,6 / 0,8 mm en option) |
| Température max de la buse | 300 °C |
| Température max du plateau | 80 °C |
| Plateaux compatibles | PEI texturé, PEI lisse (Bambu Lab) |
| Vitesse max de la tête | 500 mm/s |
| Accélération max | 10 m/s² |
| Diamètre du filament | 1,75 mm |
| Filaments idéaux | PLA, PETG, TPU, PVA |
| Filaments déconseillés | ABS, ASA, PC, PA, PET, chargés fibre de carbone ou de verre |
| Capteurs | Fin de filament, odométrie du filament, filament emmêlé, reprise après coupure de courant |
| Caméra | Basse résolution (jusqu'à 1080p), timelapse |
| Connectivité | Wi-Fi, carte micro SD |
| Encombrement | 347 × 315 × 365 mm, 5,5 kg |

## Trancheur

Bambu Studio, le trancheur du fabricant. Les trancheurs tiers qui produisent du G-code standard fonctionnent aussi, mais certaines fonctions avancées peuvent manquer (voir [Orca Slicer]({{ '/docs/logiciels/orca-slicer/' | relative_url }})).
